# Application Services

## Overview

The application services layer contains the core orchestration logic for name list generation. It consists of three main services:

1. **`NameListGenerator`** - Merges input name lists and writes output
2. **`FileContentBuilder`** - Orchestrates all names builders to produce formatted content
3. **`FileDownloader` / `CacheManager`** - Handles URL-based name acquisition with caching

## `INameListGenerator` / `NameListGenerator`

### Interface

```csharp
public interface INameListGenerator
{
    Task GenerateAsync(
        string[] inputPaths,
        string outputPath,
        string name,
        string[] leaders,
        string[] ships,
        string[] fleets,
        string[] colonies,
        bool randomized
    );
}
```

### Implementation

```csharp
public sealed class NameListGenerator : INameListGenerator
{
    private readonly IFileContentBuilder _fileContentBuilder;
    private readonly IFileRepository<NameList> _repository;

    public NameListGenerator(IFileContentBuilder fileContentBuilder, IFileRepository<NameList> repository)
    {
        _fileContentBuilder = fileContentBuilder;
        _repository = repository;
    }

    public async Task GenerateAsync(
        string[] inputPaths,
        string outputPath,
        string name,
        string[] leaders,
        string[] ships,
        string[] fleets,
        string[] colonies,
        bool randomized)
    {
        // 1. Load and merge all input name lists
        var mergedNameList = GetMergedNameList(inputPaths);

        // 2. Set metadata from CLI arguments
        mergedNameList.Id = Path.GetFileNameWithoutExtension(outputPath);
        mergedNameList.Name = name;
        mergedNameList.IsLocked = !randomized;

        // 3. Build formatted content
        var content = _fileContentBuilder.BuildContent(
            mergedNameList,
            leaders,
            ships,
            fleets,
            colonies
        );

        // 4. Write to output file
        await File.WriteAllTextAsync(outputPath, content);
    }

    private NameList GetMergedNameList(string[] inputPaths)
    {
        var merged = new NameList();

        foreach (var path in inputPaths)
        {
            var nameList = _repository.Load(path);
            merged.AddRange(nameList);
        }

        return merged;
    }
}
```

### Responsibilities

- **Input Loading**: Uses `IFileRepository<NameList>` (implemented by `XmlRepository<NameList>` from NuciDAL) to deserialize XML files
- **Merging**: Combines multiple `NameList` objects via `AddRange()` (concatenates all collections)
- **Metadata Injection**: Sets `Id`, `Name`, `IsLocked` from CLI arguments
- **Content Generation**: Delegates to `IFileContentBuilder`
- **Output Writing**: Writes final content to file

### Dependencies

- `IFileContentBuilder` - Content formatting
- `IFileRepository<NameList>` - XML deserialization (NuciDAL)

## `IFileContentBuilder` / `FileContentBuilder`

### Interface

```csharp
public interface IFileContentBuilder

}
```

### Implementation

```csharp
public sealed class FileContentBuilder : IFileContentBuilder
{
    private readonly IShipNamesBuilder _shipNamesBuilder;
    private readonly IShipClassNamesBuilder _shipClassNamesBuilder;
    private readonly IFleetNamesBuilder _fleetNamesBuilder;
    private readonly IArmyNamesBuilder _armyNamesBuilder;
    private readonly IPlanetNamesBuilder _planetNamesBuilder;
    private readonly ICharacterNamesBuilder _characterNamesBuilder;

    public FileContentBuilder(
        IShipNamesBuilder shipNamesBuilder,
        IShipClassNamesBuilder shipClassNamesBuilder,
        IFleetNamesBuilder fleetNamesBuilder,
        IArmyNamesBuilder armyNamesBuilder,
        IPlanetNamesBuilder planetNamesBuilder,
        ICharacterNamesBuilder characterNamesBuilder)
    {
        _shipNamesBuilder = shipNamesBuilder;
        _shipClassNamesBuilder = shipClassNamesBuilder;
        _fleetNamesBuilder = fleetNamesBuilder;
        _armyNamesBuilder = armyNamesBuilder;
        _planetNamesBuilder = planetNamesBuilder;
        _characterNamesBuilder = characterNamesBuilder;
    }

    public string BuildContent(
        NameList nameList,
        string[] leaders,
        string[] ships,
        string[] fleets,
        string[] colonies)
    {
        var sb = new StringBuilder();

        // Header metadata
        sb.AppendLine($"# Generated by Stellaris Name List Generator");
        sb.AppendLine($"id = \"{nameList.Id}\"");
        sb.AppendLine($"name = \"{nameList.Name}\"");
        sb.AppendLine($"randomized = {(nameList.IsLocked ? "no" : "yes")}");
        sb.AppendLine();

        // Leader names
        if (leaders.Length > 0)
        {
            sb.AppendLine($"leader_names = {{");
            foreach (var leader in leaders)
            {
                sb.AppendLine($"    \"{leader}\"");
            }
            sb.AppendLine($"}}");
            sb.AppendLine();
        }

        // Ship names
        if (ships.Length > 0)
        {
            sb.AppendLine($"ship_names = {{");
            foreach (var ship in ships)
            {
                sb.AppendLine($"    \"{ship}\"");
            }
            sb.AppendLine($"}}");
            sb.AppendLine();
        }

        // Fleet names
        if (fleets.Length > 0)
        {
            sb.AppendLine($"fleet_names = {{");
            foreach (var fleet in fleets)
            {
                sb.AppendLine($"    \"{fleet}\"");
            }
            sb.AppendLine($"}}");
            sb.AppendLine();
        }

        // Colony names
        if (colonies.Length > 0)
        {
            sb.AppendLine($"colony_names = {{");
            foreach (var colony in colonies)
            {
                sb.AppendLine($"    \"{colony}\"");
            }
            sb.AppendLine($"}}");
            sb.AppendLine();
        }

        // Generated name categories (in fixed order)
        sb.Append(_shipNamesBuilder.Build(nameList.Ships));
        sb.Append(_shipClassNamesBuilder.Build(nameList.ShipClasses));
        sb.Append(_fleetNamesBuilder.Build(nameList));
        sb.Append(_armyNamesBuilder.Build(nameList.Armies));
        sb.Append(_planetNamesBuilder.Build(nameList.Planets));
        sb.Append(_characterNamesBuilder.Build(nameList.Characters));

        return sb.ToString();
    }
}
```

### Responsibilities

- **Header Generation**: Writes metadata (id, name, randomized flag)
- **CLI Category Injection**: Inserts leader/ship/fleet/colony names from CLI arguments
- **Builder Orchestration**: Calls each names builder in fixed order:
  1. Ship names
  2. Ship class names
  3. Fleet names
  4. Army names
  5. Planet names
  6. Character names
- **Content Aggregation**: Combines all builder outputs into single string

### Dependencies

- `IShipNamesBuilder`
- `IShipClassNamesBuilder`
- `IFleetNamesBuilder`
- `IArmyNamesBuilder`
- `IPlanetNamesBuilder`
- `ICharacterNamesBuilder`

## `IFileDownloader` / `FileDownloader`

### Interface

```csharp
public interface IFileDownloader
{
    Task<string?> TryDownloadStringAsync(string url);
}
```

### Implementation

```csharp
public sealed class FileDownloader : IFileDownloader
{
    private static readonly HttpClient _httpClient = new();
    private readonly ICacheManager _cacheManager;

    public FileDownloader(ICacheManager cacheManager)
    {
        _cacheManager = cacheManager;
    }

    public async Task<string?> TryDownloadStringAsync(string url)
    {
        // 1. Check cache first
        var cached = _cacheManager.GetNameList(url);
        if (cached != null)
        {
            return cached;
        }

        // 2. Download from URL
        try
        {
            var response = await _httpClient.GetAsync(url);
            response.EnsureSuccessStatusCode();
            var content = await response.Content.ReadAsStringAsync();

            // 3. Store in cache
            _cacheManager.StoreNameList(url, content);

            return content;
        }
        catch (HttpRequestException)
        {
            return null;
        }
    }
}
```

### Responsibilities

- **Cache-First Download**: Checks `ICacheManager` before making HTTP request
- **HTTP Download**: Uses static `HttpClient` for connection pooling
- **Cache Population**: Stores successful downloads in cache
- **Error Handling**: Returns `null` on network errors (caller handles gracefully)

### Dependencies

- `ICacheManager` - File-based caching
- `HttpClient` (static) - HTTP requests

## `ICacheManager` / `CacheManager`

### Interface

```csharp
public interface ICacheManager
{
    void StoreNameList(string url, string content);
    string? GetNameList(string url);
}
```

### Implementation

```csharp
public sealed class CacheManager : ICacheManager
{
    private readonly string _cacheDirectory;
    private readonly TimeSpan _ttl = TimeSpan.FromHours(8);

    public CacheManager()
    {
        _cacheDirectory = Path.Combine(
            Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
            "StellarisNameListGenerator",
            "cache"
        );
        Directory.CreateDirectory(_cacheDirectory);
    }

    public void StoreNameList(string url, string content)
    {
        var fileName = GetCacheFileName(url);
        var filePath = Path.Combine(_cacheDirectory, fileName);
        File.WriteAllText(filePath, content);
    }

    public string? GetNameList(string url)
    {
        var fileName = GetCacheFileName(url);
        var filePath = Path.Combine(_cacheDirectory, fileName);

        if (!File.Exists(filePath))
        {
            return null;
        }

        // Check TTL
        var creationTime = File.GetCreationTimeUtc(filePath);
        if (DateTime.UtcNow - creationTime > _ttl)
        {
            File.Delete(filePath);
            return null;
        }

        return File.ReadAllText(filePath);
    }

    private string GetCacheFileName(string url)
    {
        // Create safe filename from URL
        var bytes = Encoding.UTF8.GetBytes(url);
        var hash = SHA256.HashData(bytes);
        return Convert.ToHexString(hash) + ".txt";
    }
}
```

### Responsibilities

- **File-Based Storage**: Stores cached content in `.cache/` directory under LocalApplicationData
- **TTL Enforcement**: 8-hour time-to-live based on file creation time
- **Cache Key**: SHA256 hash of URL as filename
- **Automatic Cleanup**: Expired entries deleted on access

### Dependencies

- File system only (no external dependencies)

```
    │       │       ├──► ArmyNamesBuilder
    │       │       ├──► PlanetNamesBuilder
    │       │       └──► CharacterNamesBuilder
    │       │
    │       └──► File.WriteAllTextAsync() ──► Output file
    │
    └──► (Dependency Composition)
            │
            ├──► CacheManager ──► File system (.cache/)
            │
            └──► FileDownloader ──► HttpClient ──► Network
```
